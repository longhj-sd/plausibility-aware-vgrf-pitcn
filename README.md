# Plausibility-Aware PI-TCN for Bilateral vGRF Estimation

## Manuscript

This repository supports the manuscript:

"Plausibility-Aware Physics-Informed Temporal Convolutional Modeling for Bilateral Vertical Ground Reaction Force Estimation"

## Overview

This repository contains code and configuration files for an architecture-matched comparison between a supervised temporal convolutional network and a physics-regularized TCN for bilateral vertical ground reaction force estimation from GroundLink human motion data.

The package is a public-safe reproducibility release. It includes preprocessing, model training, subject-rotation configuration, metric computation, and manuscript figure/table generation code, plus small summary tables and figure source data.

## Data availability

Raw GroundLink data are not redistributed in this repository.

Users should obtain GroundLink from the official source cited in the manuscript. After download, raw data should be placed under `data/raw/`, which is ignored by Git. The default config expects:

- `data/raw/force/` for force arrays
- `data/raw/moshpp/` for MoSh++ files

Large processed files and all-window outputs are not tracked. Processed `.npz` datasets, prediction exports, model checkpoints, all-window downstream metrics, submitted manuscript files, submitted supplementary files, cover letters, and submission packages are generated or managed outside this public repository and ignored by Git.

## Repository structure

- `configs/`: Default paths, hyperparameters, and subject split configuration.
- `scripts/`: Numbered reproducibility wrappers plus the original project scripts they call.
- `src/`: TCN, PI-TCN, and subject split source code copied from the analysis project.
- `outputs/tables/`: Small summary tables and figure source-data CSVs.
- `outputs/figures/`: Optional small figures generated by scripts; final manuscript files are not included.
- `docs/`: Minimal repository documentation; submitted manuscript and supplementary files are not included.
- `logs/`: Empty local log folder; log files are ignored.
- `data/`: Local-only raw and processed data location; ignored by Git.

## Environment

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

If you use conda, create and activate a Python environment first, then run `pip install -r requirements.txt` inside that environment.

## Reproduction workflow

The numbered scripts are thin wrappers around the real project scripts. They accept `--config configs/default.yaml`, print the underlying command, and then execute it. Use `--dry-run` to inspect the command without running it.

Full reproduction requires local GroundLink data and long-running training. This repository does not include raw data, processed arrays, checkpoints, prediction exports, manuscript DOCX/PDF files, submitted supplementary files, cover letters, submission materials, or final manuscript-formatted figures.

```powershell
python scripts/01_match_trials.py --config configs/default.yaml
python scripts/02_build_windows.py --config configs/default.yaml
python scripts/03_train_tcn.py --config configs/default.yaml
python scripts/04_train_pi_tcn.py --config configs/default.yaml
python scripts/05_run_subject_rotation.py --config configs/default.yaml
python scripts/06_compute_plausibility_metrics.py --config configs/default.yaml
python scripts/07_compute_downstream_metrics.py --config configs/default.yaml
python scripts/08_make_tables_and_figures.py --config configs/default.yaml
```

Script mapping:

| Wrapper | Calls | Purpose |
| --- | --- | --- |
| `scripts/01_match_trials.py` | `scripts/inspect_groundlink.py` | Match local GroundLink force and MoSh++ trials. |
| `scripts/02_build_windows.py` | `scripts/build_dataset.py` | Build 120-frame windowed bilateral vGRF learning arrays. |
| `scripts/03_train_tcn.py` | `src/train_tcn_baseline.py` | Train the supervised TCN baseline. |
| `scripts/04_train_pi_tcn.py` | `src/train_pi_tcn.py` | Train the PI-TCN with non-negativity, contact, and smoothness losses. |
| `scripts/05_run_subject_rotation.py` | `scripts/run_revision_evidence.py` | Run seven-fold subject-rotation training for TCN and PI-TCN-full. |
| `scripts/06_compute_plausibility_metrics.py` | `scripts/evaluate_physical_plausibility.py` | Compute accuracy and physical-plausibility metrics from trained models. |
| `scripts/07_compute_downstream_metrics.py` | `scripts/compute_final_downstream_vgrf_metrics.py` | Compute downstream diagnostics from local prediction exports. |
| `scripts/08_make_tables_and_figures.py` | `scripts/create_final_results_package.py` | Regenerate manuscript-oriented summary tables and workflow figure from local result CSVs. |

Additional copied scripts support final figure/table construction:

- `scripts/create_final_revision_figures.py`
- `scripts/create_final_downstream_figures.py`
- `scripts/create_final_paired_subject_rotation_comparison.py`

## Expected outputs

Running the workflow with local GroundLink data produces:

- subject-rotation accuracy summaries;
- physical-plausibility summaries;
- downstream vGRF-derived diagnostics;
- manuscript-oriented tables and optional script-generated diagnostic figures.

The release includes small summary tables and figure source-data CSVs under `outputs/` for transparency. Final manuscript-formatted figures, submitted supplementary files, large all-window outputs, and raw/intermediate arrays are intentionally excluded.
