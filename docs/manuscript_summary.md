# Manuscript Summary

This package supports the manuscript:

Plausibility-Aware Physics-Informed Temporal Convolutional Modeling for Bilateral Vertical Ground Reaction Force Estimation

The repository contains public-safe code, configuration, small summary tables, and figure source-data CSV files for reproducing the architecture-matched comparison between a supervised TCN and a physics-regularized TCN for bilateral vertical ground reaction force estimation from GroundLink human motion data.

The release does not redistribute raw GroundLink data, processed window arrays, trained weights, prediction arrays, all-window downstream metrics, manuscript Word/PDF files, submitted supplementary files, final manuscript-formatted figures, cover letters, or journal submission material.
